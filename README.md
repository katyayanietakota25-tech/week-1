
# Week 1 - Prompt Engineering Lab

## Aim
To establish a working environment for prompt engineering
and test connectivity with the Gemini API.

## Technologies Used
- Python
- Google Gemini API
- Google Colab

## Installation
Install the required library:

```bash
pip install -r requirements.txt
```

## Execution
Run the Python program:

```bash
python connectivity.py
```

Enter your Gemini API key when prompted.

## Experiment
The program sends two prompts to the Gemini model
and displays the generated responses.

## Result
Successfully connected to the Gemini API and verified
prompt submission and response generation.

## Security
Never upload your API key to GitHub.
